# OctoAcme Project Management Process Docs

This README collects and links the OctoAcme project management process documents stored in the docs/ folder, and provides a short summary of the processes for quick reference.

## Summary of OctoAcme Project Management Processes

OctoAcme runs cross-functional projects with a focus on iterative delivery, clear ownership, and data-informed decisions. Key phases:

- Initiation: create a Project One-pager to capture problem, goals, success metrics, stakeholders, and a high-level timeline. Use this to decide whether to move into planning.
- Planning: turn the approved one-pager into a prioritized backlog, estimates, Definition of Done, and a release/milestone plan. Capture risks, dependencies, and test/QA approaches.
- Execution & Tracking: deliver in small increments with daily standups, a project board for task flow, PR-based code reviews, CI checks, and weekly delivery syncs. Track velocity and metrics.
- Release & Deployment: follow pre-release checks (CI, security scans, release notes), run smoke tests in staging, deploy via automated pipelines where possible, and have rollback plans and incident playbooks.
- Retrospective & Continuous Improvement: run retros after sprints/releases/incidents, capture 2–3 action items, track improvements, and add follow-ups to the backlog.

Regular cadences: daily standups, weekly delivery syncs, and monthly stakeholder updates.
